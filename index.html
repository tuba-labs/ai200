AI-200

Developing AI Cloud Solutions on Azure

AI-200 er en Microsoft-sertifisering for utviklere som bygger, integrerer og drifter AI-løsninger i Azure. Den handler først og fremst om infrastrukturen rundt AI, ikke om å utvikle eller trene AI-modeller.

Eksamen dekker containere og Kubernetes, databaser og AI-data, integrasjoner, samt sikkerhet, overvåking og feilsøking. Den passer særlig for backend- og skyutviklere som bygger produksjonsklare AI-systemer.

Containere på Azure

Images og hosting

DOMENE 0225–30 %

Datatjenester for AI

12 delmål

Cosmos DB for NoSQL

  1. Koble til Cosmos DB og kjør SDK-spørringer.
  2. Optimaliser spørringer og RU-forbruk med indeks- og konsistensvalg.
  3. Lagre/hent embeddings og utfør semantisk vektorsøk.
  4. Behandle nye/endrede dokumenter med change feed-prosessor.

PostgreSQL

  1. Koble til PostgreSQL og kjør SDK-spørringer.
  2. Modeller tabeller, datatyper og indekser.
  3. Optimaliser spørringslatens og pgvector-ressursbruk med indekser.
  4. Dimensjoner CPU, minne og lagring for vektorer.
  5. Bruk embeddings, metadatafiltre og vektorsøk i RAG.
  6. Optimaliser forbindelser for kapasitet og responstid.

Azure Managed Redis

  1. Implementer Redis-caching, utløp og invalidering.
  2. Indekser Redis-vektorer for likhetssøk.
