AI-200

Developing AI Cloud Solutions on Azure

AI-200 er en Microsoft-sertifisering for utviklere som bygger, integrerer og drifter AI-løsninger i Azure. Den handler først og fremst om infrastrukturen rundt AI, ikke om å utvikle eller trene AI-modeller.

Eksamen dekker containere og Kubernetes, databaser og AI-data, integrasjoner, samt sikkerhet, overvåking og feilsøking. Den passer særlig for backend- og skyutviklere som bygger produksjonsklare AI-systemer.

Pensum

De fire domenene

Vektingen nedenfor følger Microsofts oppdaterte studieguide fra 7. oktober 2026. Prosentene er intervaller, ikke en fast fordeling.

DOMENE 0120–25 %

Containerized Solutions

Bygging, utrulling, skalering og feilsøking av applikasjoner i containere.

  • Docker-images og Azure Container Registry (ACR/ACR Tasks)
  • Azure App Service og Azure Container Apps
  • AKS/Kubernetes, manifests og utrulling
  • KEDA-autoskalering, logging og feilsøking
Typisk spørsmål: Hvilken tjeneste eller konfigurasjon skal brukes?
DOMENE 0230–35 %

AI Data Management

Datatilgang, søk, vektordata og ytelse for AI-baserte applikasjoner.

  • Azure Cosmos DB for NoSQL, SDK, RU og consistency
  • PostgreSQL med pgvector, indekser og tuning
  • Azure Managed Redis, caching og utløp
  • Embeddings, vektorsøk, RAG og ytelsesoptimalisering
Største domene: bør få tilsvarende mye studietid.
DOMENE 0320–25 %

Connect and Consume Azure Services

Hendelsesdrevet integrasjon og meldingstjenester.

  • Azure Service Bus: queues, topics, subscriptions og DLQ
  • Azure Event Grid: hendelser, filtre og retry
  • Azure Functions: triggers, bindings og serverless API-er
  • Konfigurasjon og utrulling av Function Apps
Typisk spørsmål: Event Grid, Service Bus eller Functions?
DOMENE 0420–25 %

Secure, Monitor and Troubleshoot

Beskyttelse av konfigurasjon og feilsøking i distribuerte løsninger.

  • Azure Key Vault: hemmeligheter, oppslag og rotasjon
  • Azure App Configuration: konfigurasjon
  • OpenTelemetry og distribuert tracing
  • KQL for analyse av logger og målinger
Typisk spørsmål: Hvor finner du feilen, og hvordan sikrer du tjenesten?

Merk: Den offisielle studieguiden hadde per 26.10.2026 en eldre prosentsats i én underoverskrift for domene 2. Oversikten «Skills at a glance» og endringsloggen angir at vektingen er økt til 30–35 %.

Praktisk informasjon

Oppmelding og gjennomføring

AI-200 kan normalt tas med digital eksamensvakt hjemmefra eller ved et Pearson VUE-testsenter. Tilgjengelige testsentre i Oslo-området bekreftes ved bestilling.

På eksamensdagen

  • Varighet: 120 minutter.
  • Bestått: minst 700 poeng av 1000.
  • Format: overvåket eksamen med potensielt interaktive oppgaver.
  • Språk: blant annet engelsk; norsk står ikke på Microsofts språkoversikt.
  • Online: fullfør systemtesten, kontroller legitimasjon og følg reglene for rom og utstyr.

Retake og vedlikehold

Ved stryk tillater Microsoft normalt nytt forsøk etter 24 timer første gang, deretter gjelder lengre ventetider. Et nytt forsøk er ikke automatisk gratis uten en gjeldende kampanje eller annen ordning.

Associate-sertifiseringer fornyes vanligvis årlig med en gratis online vurdering på Microsoft Learn.

Pearson VUE – Microsoft ↗

Tidsbegrenset kampanje: ett gratis nytt forsøk ved stryk

Pearson VUE har en kampanje for deltakende eksamensprogrammer, inkludert Microsoft. For å kvalifisere må du melde deg på kampanjen, bruke tilsendt kode og bestille, betale for og ta første eksamen i perioden 29. september–17. november 2026. Ved stryk kan ett gratis nytt forsøk gjennomføres 4. januar–7. april 2027.

Viktig: Microsoft ESI er unntatt. Ordningen kan ikke kombineres med andre kampanjer, og øvrige vilkår gjelder. Kontroller betingelsene før oppmelding.
