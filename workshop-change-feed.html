Bygger på: 9. Cosmos DB: SDK, indekser og RU.

Gjennomføringstiden er ikke målt. Sett av tid til å forklare valgene og prøve egne varianter. Følg klargjøringen i denne delen før oppgavene. Python-øvelsene bruker samme .venv i prosjektroten. Start kommandoene i prosjektmappen du åpnet i IntelliJ, der ikke annet er angitt.

Bruk egne labressurser og rydd opp etter bruk. Kostnadsveiledning (valgfritt).

Før du starter

Bruk notes-containeren fra workshop 9, Azure Functions Core Tools v4 og en lab-Storage-konto. Kjør Python-aktivering fra prosjektroten. Kopier innstillingseksemplet til local.settings.json og erstatt begge connection strings med labverdier.

.\.venv\Scripts\Activate.ps1
python -m pip install -r artifacts/labs/cosmos/requirements.txt
if (-not (Test-Path artifacts/labs/cosmos/local.settings.json)) {
    Copy-Item artifacts/labs/cosmos/local.settings.example.json artifacts/labs/cosmos/local.settings.json
}
Set-Location artifacts/labs/cosmos
func start

1. Observer nye endringer

Ha COSMOS_ENDPOINT, COSMOS_KEY og COSMOS_DATABASE satt i en annen, aktivert terminal i prosjektroten. Kjør:

python artifacts/labs/cosmos/demo.py update

Forventet: Function-loggen viser changed id=note-1 med ny revision. Finn cosmos_db_trigger. Dette er en change feed-prosessor med checkpoint i lease-containeren; den erstatter polling du ellers måtte håndtert selv.

2. Restart og undersøk leases

Finn leases i databasen. Stopp Functions-host, oppdater note-1 to ganger, og start host-en igjen. Observer at behandlingen fortsetter fra checkpoint. Sammenlign siste endringsversjon med applikasjonens behov: standard latest-version feed er ikke en komplett historikk over alle mellomliggende tilstander eller slettinger.

3. Gjør behandlingen robust

Forklar hvorfor sideeffekter må tåle gjentatt levering. Utvid logglinjen med dokumentets _etag og diskuter en varig nøkkel for en indeksoppdatering. I denne laben er sideeffekten bare logging; en applikasjon må registrere ferdig behandling før den kan stole på deduplisering.

Rydd opp

Stopp host-en. Slett local.settings.json med labnøklene og slett den dedikerte Cosmos-kontoen/Storage-kontoen når du er ferdig. Slett ikke leases for en prosessor som skal fortsette; det kan endre hvor behandlingen starter.
