YAML · Kubernetes: eksempel

Describes a Kubernetes Deployment with two web-server pods.

deployment.yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: hello-web
spec:
  replicas: 2
  selector:
    matchLabels:
      app: hello-web
  template:
    metadata:
      labels:
        app: hello-web
    spec:
      containers:
        - name: web
          image: nginx:stable-alpine
          ports:
            - containerPort: 80
          resources:
            requests:
              cpu: "100m"
              memory: "64Mi"
            limits:
              cpu: "250m"
              memory: "128Mi"

Last ned deployment.yaml

Hva viser eksemplet?

  • apiVersion and kind identify the Kubernetes resource. metadata.name gives the Deployment its name.
  • replicas: 2 requests two pods. The selector matches the labels in the pod template.
  • The container runs nginx on port 80. Its requests reserve 0.1 CPU core and 64 MiB; the limits cap CPU at 0.25 core and memory at 128 MiB.
