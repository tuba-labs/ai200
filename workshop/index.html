Chapter 01 of 10

A small system, end to end

Deploy a product-manual assistant using containers, events and grounded RAG.

~15 minBash · repository root

Build and deploy a product-manual assistant: upload text, index it, then ask questions with cited answers. All application code is supplied.

Before you start

  • Azure: an active subscription, resource/role-assignment permissions, and model/VM quota.
  • Local: Azure CLI, Bicep, Docker, kubectl, Java 21, Python 3.12+ and Git. On Windows, use Ubuntu in WSL2 with Docker Desktop integration.

Use the prerequisite checklist and setup downloads. Allow about four hours after setup; this estimate has not been timed.

The three applications

ApplicationResponsibility
ProductsJava 21 / Spring Boot on AKS. Server-rendered upload/chat UI; JDBC, PostgreSQL and Flyway. Always at least one replica.
ProductsEmbedderPython Function. Reads uploaded manuals, creates chunks/embeddings and stores them in pgvector.
ProductsChatPython worker on AKS. Retrieves chunks, calls the chat model and replies through Service Bus. KEDA scales it from zero.
