Chapter 07 of 10

Turn a manual into vectors

Trigger Python indexing from a Blob upload; verify stored chunks.

~30 minBash · repository root

Requires: Products ready, Flyway applied and model probe passed.

How the Event Grid Blob trigger works

function_app.py declares a Blob trigger with source='EventGrid'. A BlobCreated notification reaches the Blob-extension webhook; the extension reads the private blob and passes an InputStream to Python. The path carries product/manual IDs.

Publish

Bash · repository root
bash workshop/scripts/07-embedder.sh

Canonical commands: commands.sh

The stage builds the Python package remotely on Linux, publishes it, then registers the filtered Event Grid subscription. Flex Consumption supplies server-managed execution; the template supplies VNet access, identity-based host/deployment storage and telemetry.

Inspect stored data

Bash · repository root
bash workshop/scripts/inspect-data.sh

Canonical commands: commands.sh

Verification: all three manuals are ready, chunk counts are positive and min/max dimensions equal 1536. The inspection Job runs inside the VNet; it does not print full vectors.

Make two changes

  1. Copy Aurora's manual, change 420 lumens to 510 lumens, and label it revision B. Upload as a new product, "Aurora Trail Lamp Rev B". Compare each product's answer in the next chapter.
  2. Activate the verification environment, run python workshop/tools/replay_event.py, then inspect counts again. Replaying a ready manual twice should add no chunks.
Chunking and retry safety

chunks.py splits at text boundaries with bounded character counts/overlap. models.py requests 1536-value embeddings. embedding.py locks per manual, checks IDs/checksum, persists processing, then commits chunks + ready atomically.

A ready manual skips indexing. Duplicate Blob receipts may be suppressed before code runs; the database guard also prevents duplicates. Failed attempts persist errors and retry. Delivery is at-least-once; manuals are immutable.

Troubleshooting
  • Still waiting: check subscription/filter and IndexManual discovery. For uploads made before subscription creation, upload a new product.
  • No Function/key: check remote-build logs, extension bundle and host-storage roles: Blob Data Owner, Queue Data Contributor, Storage Account Contributor.
  • Indexing failed: use the manual ID in Application Insights; check DB DNS, model identity/quota and dimensions.
  • Delivery exhausted: inspect Event Grid's event-deadletters blobs separately from the Function host's webjobs-blobtrigger-poison queue.
