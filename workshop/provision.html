Chapter 03 of 9

Start the Azure resources

Test model access, then provision Azure while you build locally.

~20 minBash · repository root

Requires: prerequisite checks pass; subscription, region and source IP reviewed.

Cost check

This creates paid resources. Allow roughly US$5–15 for 3½ hours with prompt cleanup (11 November 2026 estimate, not a measured bill). VM, PostgreSQL, NAT and service tiers continue billing while the worker is idle. Cost details.

Start provisioning

Bash · repository root
bash workshop/scripts/01-models.sh
bash workshop/scripts/02-provision.sh

Canonical commands: commands.sh

  • 01 → models: creates the tagged resource group and model deployments, then makes identity-based embedding/chat calls. AKS/database creation waits for this gate.
  • 02 → infrastructure: creates networking, ACR, Storage, queues, Key Vault, App Configuration, identities and telemetry; starts PostgreSQL and AKS/Functions deployments asynchronously.

Defaults: gpt-5-mini + text-embedding-3-small, 1536 dimensions, PostgreSQL 17, one AKS node, Python 3.12 Functions Flex. Passwords go into Key Vault; never enable set -x.

Templates: models.bicep, foundation.bicep, database.bicep, compute.bicep. Separate delegated subnets provide Functions/DB integration. GlobalStandard model processing may occur outside the account region.

Build while Azure runs

Continue directly to Products. Stage 03 later checks readiness, with bounded waits and failed-operation diagnostics. Accepted deployments are not yet ready.

Verification: the model probe passes and the script reports AKS/Functions and PostgreSQL provisioning. These are expected results; observed validation is recorded separately.
Troubleshooting
  • Model probe fails: fix model access/quota/region before starting compute.
  • ARM failure: inspect the reported operation for policy, SKU or regional restrictions.
  • Name reserved/soft-deleted: recover your own resource or use a new prefix; do not adopt another group's resources.
  • Interrupted: rerun the same stage/config. Scripts reuse matching resources and reject a group with another workshop tag.
