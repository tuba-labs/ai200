Workshop 02 / Domene 1 / Containere

Lagre images og bygg med ACR Tasks

Bygg og kjør images i Azure Container Registry, og finn igjen tagger, digester og task-logger.

På denne siden

Før du starter 1. Bygg i ACR 2. Bygg, push og kjør med Tasks 3. Hent og kjør Rydd opp Pensum og kilder

Bygger på: 1. Bygg og feilsøk et container-image.

Tidsanslaget gjelder med verktøy og eventuelle ressurser under «Klargjør før økten» klare. Python-øvelsene bruker samme .venv i prosjektroten. Kommandoene starter i prosjektroten der ikke annet er angitt.

Bruk egne labressurser og rydd opp etter bruk. Kostnadsveiledning (valgfritt).

Før du starter · 10 min

Ha Azure CLI innlogget, labfilene fra workshop 1 og et eget Basic-registry klart. Opprett det i portalen med administratorkonto deaktivert. Bruk registerets tilgangsmodell til å gi din bruker rett til image-operasjoner og Tasks. Registrer navnene i terminalen.

$acr = "DITT-REGISTRY-NAVN"
$rg = "DIN-LAB-GRUPPE"
$login = az acr show --name $acr --query loginServer -o tsv

1. Bygg i ACR · 15 min

az acr build --registry $acr --image ai200-api:v1 labs/containers
az acr repository show-tags --name $acr --repository ai200-api --detail -o table

Bygget og lagringen skjer i Azure. Finn tagg og digest. En gjenbrukt tagg kan peke på nytt innhold; digest identifiserer innholdet. Kjør bygget med en ny tagg og sammenlign.

2. Bygg, push og kjør med Tasks · 20 min

acr-task.yaml bygger med run-ID som tagg, lagrer imaget og kjører python --version i det.

Set-Location labs/containers
az acr run --registry $acr --file acr-task.yaml .
Set-Location ../..
az acr task list-runs --registry $acr -o table

Forventet: alle tre stegene fullføres, og Python-versjonen står i loggen. Finn task-kjøringen og den unike taggen. Forklar forskjellen mellom denne manuelle kjøringen og triggere fra kildekode, base-image eller tidsplan.

3. Hent og kjør · 10 min

az acr login --name $acr
docker pull "$login/ai200-api:v1"
docker run --rm "$login/ai200-api:v1" python --version

Samme image kan brukes av App Service, Container Apps og AKS i de neste øktene.

Rydd opp · 5 min

Behold registryet bare mens workshop 3–6 bruker det. Slett egne ubrukte testtagger i repository-visningen. Når siste avhengige økt er ferdig, slett labregistryet eller labgruppen.
