Oppsett for denne delen

Docker må kjøre. Bruk labs/data/setup.sql som ferdig datasett, og lagre egne spørringer i artifacts/queries.sql. Vektorene er små undervisningstall; øvelsen undersøker lagring, avstand og gjenfinning.

setup.sql — vis fil og forklaring

Kildefil: labs/data/setup.sql

-- Aktiver pgvector-utvidelsen i den valgte databasen.
CREATE EXTENSION IF NOT EXISTS vector;

-- Opprett labtabellen hvis den ikke finnes fra før.
CREATE TABLE IF NOT EXISTS workshop_notes (
    -- Gi hver rad en entydig identifikator.
    id integer PRIMARY KEY,
    -- Bruk topic som metadatafilter i søkene.
    topic text NOT NULL,
    -- Lagre teksten som et senere RAG-steg kan hente frem.
    content text NOT NULL,
    -- Lagre nøyaktig tre komponenter per undervisningsvektor.
    embedding vector(3) NOT NULL
);

-- Hand-written teaching vectors, not output from an embedding model.
-- Sett inn fire eksempler. Vektorene er skrevet for hånd, ikke generert av en modell.
INSERT INTO workshop_notes (id, topic, content, embedding) VALUES
    -- Første containerdokument peker langs første vektordimensjon.
    (1, 'containers', 'A container packages an application and its dependencies.', '[1,0,0]'),
    -- Andre containerdokument ligger nær det første i vektorrommet.
    (2, 'containers', 'Read container logs when an application fails to start.', '[0.9,0.1,0]'),
    -- Datadokumentet ligger nær spørsmålsvektoren, men kan filtreres bort av topic.
    (3, 'data', 'A database stores and retrieves application data.', '[0,1,0]'),
    -- Sikkerhetsdokumentet gir oss et eksempel i et annet emne.
    (4, 'security', 'Managed identity removes the need to store a credential.', '[0,0,1]')
-- Oppdater eksisterende rader når skriptet kjøres på nytt.
ON CONFLICT (id) DO UPDATE SET
    -- Bruk emnet fra raden vi forsøkte å sette inn.
    topic = EXCLUDED.topic,
    -- Oppdater teksten til verdien i eksempeldatasettet.
    content = EXCLUDED.content,
    -- Oppdater også vektoren, og avslutt SQL-setningen.
    embedding = EXCLUDED.embedding;

1. Start database og schema

# Start en lokal PostgreSQL 17-container med pgvector og databasen workshop.
docker run --detach --name ai200-pg --env POSTGRES_PASSWORD=local-workshop-only --env POSTGRES_DB=workshop pgvector/pgvector:pg17
# Kontroller at PostgreSQL-containeren er klar til å motta forbindelser.
docker exec ai200-pg pg_isready -U postgres -d workshop
# Send SQL-filen til psql i containeren for å opprette schema og eksempeldata.
Get-Content labs/data/setup.sql -Raw | docker exec -i ai200-pg psql -U postgres -d workshop
# Åpne en interaktiv psql-terminal mot databasen workshop.
docker exec -it ai200-pg psql -U postgres -d workshop

Vent på accepting connections før setup. Tabellen har id, topic, textinnhold og vector(3). Forklar valg av primærnøkkel og dimensjoner.

2. Søk og filtrer

-- Hent dokumentfeltene og beregn cosinusavstand til spørsmålsvektoren.
SELECT id, topic, content, embedding <=> '[0,1,0]'::vector AS distance
-- Les radene fra labtabellen workshop_notes.
FROM workshop_notes
-- Ta bare med dokumenter som har emnet containers.
WHERE topic = 'containers'
-- Sorter dokumentene etter økende cosinusavstand.
ORDER BY embedding <=> '[0,1,0]'::vector
-- Returner bare de to nærmeste dokumentene.
LIMIT 2;

Forventet: dokument 2 før 1. Uten filter er dokument 3 nærmest. Forklar hvordan et metadatafilter avgrenser RAG-konteksten før en språkmodell eventuelt bruker treffene.

3. Les planen og bygg indeks

-- Opprett den navngitte indeksen hvis den ikke finnes fra før.
CREATE INDEX IF NOT EXISTS notes_embedding_hnsw
-- Bygg en HNSW-indeks på embedding med operatorer for cosinusavstand.
ON workshop_notes USING hnsw (embedding vector_cosine_ops);
-- Kjør neste spørring og vis planen, målt tidsbruk og bufferaktivitet.
EXPLAIN (ANALYZE, BUFFERS)
-- Hent dokumentenes ID-er fra labtabellen.
SELECT id FROM workshop_notes
-- Sorter etter cosinusavstand og begrens resultatet til to dokumenter.
ORDER BY embedding <=> '[0,1,0]'::vector LIMIT 2;

Fire rader er ofte for lite til at indeksen lønner seg; Seq Scan er normalt. Sammenlign operator og operator class. Beskriv avveiningen mellom recall, minne og svartid for en større vektorindeks.

Rydd opp

Avslutt psql med \q. Ta vare på SQL-endringene dine og fjern labcontainerens data.

# Stopp labdatabasen før containeren fjernes.
docker stop ai200-pg
# Fjern den stoppede PostgreSQL-containeren og dens anonyme datavolumer.
docker rm --volumes ai200-pg
