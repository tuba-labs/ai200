Q: Which pgvector operator and index operator class implement negative inner product?
A: Use <#> with vector_ip_ops for the matching index.

An inner product (dot product) multiplies matching vector components and adds them:
[1,2] · [3,4] = 1×3 + 2×4 = 11.
Negative inner product means negating that sum, so <#> returns -11. If the dot product were -2, it would return +2.

The dot product depends on both vector direction and length. For vectors normalized to length 1, it equals cosine similarity.
