Før du starter

Opprett en App Configuration-labressurs, for eksempel Free hvis tilgjengelig. Gi deg selv App Configuration Data Owner for å legge inn verdier. Bruk prosjektets .venv og artifacts/labs/security/requirements.txt. Innstillingene skal være vanlig konfigurasjon; hemmeligheter hører til i Key Vault.

read_settings.py — vis fil og forklaring

Arbeidskopi: artifacts/labs/security/read_settings.py

"""Optional Azure exercise: read a demo secret and ordinary configuration via Entra ID."""

# Velg Key Vault-hemmelighet eller vanlig appkonfigurasjon.
import argparse
# Les tjenestenes endpoint fra miljøet.
import os

# Les nøkkel-/etikettverdier fra App Configuration.
from azure.appconfiguration import AzureAppConfigurationClient
# Bruk Entra-identitet, for eksempel Azure CLI-innlogging på egen maskin.
from azure.identity import DefaultAzureCredential
# Les hemmeligheter gjennom Key Vaults data-API.
from azure.keyvault.secrets import SecretClient

# Kjør ett oppslag mot den valgte tjenesten.
def main():
    # Opprett kommandolinjeparseren.
    parser = argparse.ArgumentParser()
    # Tillat bare de to oppslagstypene.
    parser.add_argument("mode", choices=["secret", "config"])
    # Les valgt oppslagstype.
    args = parser.parse_args()
    # Gjenbruk samme identitetsoppsett for begge tjenester.
    with DefaultAzureCredential() as credential:
        # Key Vault-operasjonen krever tilgang til hemmelighetens verdi.
        if args.mode == "secret":
            # Åpne klienten for ditt labhvelv.
            with SecretClient(vault_url=os.environ["KEY_VAULT_URL"], credential=credential) as vault:
                # Les gjeldende versjon av demo-secret.
                secret = vault.get_secret("demo-secret")
                # Vis bare at verdien ble lest, aldri selve hemmeligheten.
                print("Secret read successfully:", bool(secret.value))
                # Bruk versjons-ID til å observere rotasjon.
                print("Secret version:", secret.properties.version)
            # Avslutt etter Key Vault-oppslaget.
            return
        # Åpne klienten for vanlig konfigurasjon.
        with AzureAppConfigurationClient(
            # Bruk App Configuration-endpoint og den samme Entra-identiteten.
            base_url=os.environ["APP_CONFIG_ENDPOINT"], credential=credential
        # Lukk konfigurasjonsklienten etter bruk.
        ) as config:
            # Les akkurat nøkkelen og miljøetiketten som ble opprettet i portalen.
            setting = config.get_configuration_setting(key="Workshop:Mode", label="lab")
            # Vis den vanlige konfigurasjonsverdien i terminalen.
            print("Workshop mode:", setting.value)


# Start bare når filen kjøres direkte.
if __name__ == "__main__":
    # Kjør valgt konfigurasjonsoppslag.
    main()

1. Lag to verdier med etiketter

I Configuration explorer: opprett nøkkel Workshop:Mode, label lab, verdi practice. Legg samme nøkkel med label test og verdi review. Finn endpoint på Overview.

2. Les med SDK

$env:APP_CONFIG_ENDPOINT = "https://DITT-NAVN.azconfig.io"
python artifacts/labs/security/read_settings.py config

Forventet: Workshop mode: practice. Finn label=lab i koden. Endre label til test i arbeidskopien og kontroller review. Før neste steg, gjenopprett filen med label=lab og kjør oppslaget igjen:

# Fra prosjektroten. Overskriver endringene i arbeidsfilen.
Copy-Item -LiteralPath labs/security/read_settings.py -Destination artifacts/labs/security/read_settings.py -Force
python artifacts/labs/security/read_settings.py config

Forventet: Workshop mode: practice. For en driftet app som bare leser, holder Data Reader.

3. Endre uten nytt image

Endre lab-verdien i portalen og kjør skriptet igjen. Forklar hvorfor dette korte programmet leser på nytt hver gang. En langlivet prosess trenger en bevisst strategi for refresh og cache; nytt portalinnhold alene endrer ikke gamle verdier i minnet.

Rydd opp

Remove-Item Env:APP_CONFIG_ENDPOINT -ErrorAction SilentlyContinue

Slett labressursen. Forklar hvilke av konfigurasjonsverdiene i dine tidligere øvelser som passer i App Configuration, Key Vault eller appens egne innstillinger.
