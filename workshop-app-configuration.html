Bygger på: 19. Key Vault: oppslag, identitet og rotasjon.

Gjennomføringstiden er ikke målt. Sett av tid til å forklare valgene og prøve egne varianter. Følg klargjøringen i denne delen før oppgavene. Python-øvelsene bruker samme .venv i prosjektroten. Start kommandoene i prosjektmappen du åpnet i IntelliJ, der ikke annet er angitt.

Bruk egne labressurser og rydd opp etter bruk. Kostnadsveiledning (valgfritt).

Før du starter

Opprett en App Configuration-labressurs, for eksempel Free hvis tilgjengelig. Gi deg selv App Configuration Data Owner for å legge inn verdier. Bruk prosjektets .venv og labs/security/requirements.txt. Innstillingene skal være vanlig konfigurasjon; hemmeligheter hører til i Key Vault.

1. Lag to verdier med etiketter

I Configuration explorer: opprett nøkkel Workshop:Mode, label lab, verdi practice. Legg samme nøkkel med label test og verdi review. Finn endpoint på Overview.

2. Les med SDK

$env:APP_CONFIG_ENDPOINT = "https://DITT-NAVN.azconfig.io"
python labs/security/read_settings.py config

Forventet: Workshop mode: practice. Finn label=lab i koden. Endre label til test i en lokal kopi og kontroller review. For en driftet app som bare leser, holder Data Reader.

3. Endre uten nytt image

Endre lab-verdien i portalen og kjør skriptet igjen. Forklar hvorfor dette korte programmet leser på nytt hver gang. En langlivet prosess trenger en bevisst strategi for refresh og cache; nytt portalinnhold alene endrer ikke gamle verdier i minnet.

Rydd opp

Remove-Item Env:APP_CONFIG_ENDPOINT -ErrorAction SilentlyContinue

Slett labressursen. Forklar hvilke av konfigurasjonsverdiene i dine tidligere øvelser som passer i App Configuration, Key Vault eller appens egne innstillinger.
