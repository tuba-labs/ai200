Workshop 14 / Domene 3 / Integrasjoner

Bygg og publiser en HTTP Function

Kjør et serverless HTTP-API lokalt, test feil og publiser en Python Function App.

På denne siden

Følg Kom i gang før økten.

Gjennomføringstiden er ikke målt. Sett av tid til å forklare valgene og prøve egne varianter. Klargjør verktøy og eventuelle ressurser under «Klargjør før økten» før du starter. Python-øvelsene bruker samme .venv i prosjektroten. Kommandoene starter i prosjektroten der ikke annet er angitt.

Bruk egne labressurser og rydd opp etter bruk. Kostnadsveiledning (valgfritt).

Før du starter

Python 3.12, prosjektets .venv og Functions Core Tools v4 må være klare. Ha en Python 3.12 Function App på Linux med tilhørende Storage-konto klargjort i en egen labgruppe. Bruk en støttet hostingplan. Vi arbeider i labs/integrations.

.\.venv\Scripts\Activate.ps1
python -m pip install -r labs/integrations/requirements.txt
Copy-Item labs/integrations/local.settings.example.json labs/integrations/local.settings.json
Set-Location labs/integrations
func start

1. Test en HTTP-trigger

La host-en kjøre. Send fra en ny PowerShell-terminal:

$body = @{ id = "doc-001"; text = "Workshop" } | ConvertTo-Json
Invoke-RestMethod http://localhost:7071/api/documents -Method Post -ContentType application/json -Body $body

Forventet: processed=true første gang og false ved samme ID. Finn route, trigger og HTTP-respons i function_app.py.

2. Undersøk feil og restart

Invoke-RestMethod http://localhost:7071/api/documents -Method Post -ContentType application/json -Body '{}'

Forventet HTTP 400. Restart host-en og send doc-001 igjen: minnesettet er tømt. Forklar hvorfor HTTP-triggeren ikke gjentar klientens kall, og hvorfor varig idempotens trenger mer enn prosessminne.

3. Publiser og konfigurer

Stopp host-en. Fra labs/integrations, med miljøet aktivt:

az login
az account show --query "{name:name,id:id}" -o table
func azure functionapp publish "DITT-FUNCTION-APP-NAVN"

Finn Get Function URL for documents i portalen og send samme body til den komplette URL-en med nøkkel. Undersøk Function-logger og appinnstillingen FUNCTIONS_WORKER_RUNTIME. Behold appnavnet til workshop 18–19; de bruker event-hook og configuration-endepunktene fra samme kode.

Rydd opp

Stopp lokal host. Slett appen og den dedikerte Storage-kontoen når du er ferdig med øvelsene som bruker dem. Dersom du tar workshop 18–19 senere, kan du publisere samme kode på nytt.
